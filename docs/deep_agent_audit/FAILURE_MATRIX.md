# FAILURE MATRIX — everything the live audit found

Every entry was observed against the running system: real local PostgreSQL,
real pgvector corpora, real OpenAI provider, real DeepAgent runtime. Transcripts
are in `eval/conversations/`. Each defect has a regression test in
`tests/test_agents/test_live_audit_regressions.py`.

Severity: **C** critical (wrong clinical content, or the conversation cannot
finish) · **H** high · **M** medium · **I** informational/risk.
